# Renfild — терминал

Одностраничный сайт-портфолио. Страница открывается кадром стола: камера подъезжает к монитору, командная строка живёт на его экране. Стол можно крутить мышью, клавиши печатают команды и сами нажимаются, когда вы печатаете, неоновые вывески открывают проекты. Лампа слева включается щелчком, рыжий кот справа просыпается, если его погладить.

При первом входе за сессию компьютер выключен: щелчок или любая клавиша запускают короткую загрузку, Esc её пропускает.

Кот на столе — демо tamagotchi-bot: `cat` показывает сытость и настроение, `feed`, `play` и `pet` за ним ухаживают, состояние живёт в браузере и со временем падает. Телефон слева — рабочая копия Mini App из tgbotshop: команда `shop` или щелчок по телефону, дальше каталог, размеры, корзина, промокод `RENFILD` и оформление заказа.

Щелчок по монитору (или кнопка «приблизить экран») подводит камеру вплотную к экрану, Esc возвращает её к столу.

Звук включается кнопкой «звук» в правом верхнем углу или командой `sound` (`sound on`, `sound off`). Всё звучание синтезируется в браузере через WebAudio: дождь и гул города, щелчки клавиш, выключатель лампы, мурлыканье кота. Выбор запоминается в браузере.

```bash
python3 -m http.server 4173
```

Откройте http://127.0.0.1:4173

Файл по двойному щелчку не заработает: странице нужен локальный сервер из-за модулей JavaScript.

Почта для команды `contact` задаётся в `js/data.js`, поле `profile.email`. Пока оно пустое, терминал показывает только GitHub.

Тексты кейсов собраны из публичных репозиториев, срез GitHub API от 28 сентября 2026.

## Качество картинки

Разрешение сцены подстраивается под реальную скорость кадров: слабый телефон или ноутбук без дискретной видеокарты шаг за шагом снижает плотность пикселей, мощная машина получает её обратно. Параметр адреса фиксирует качество, например для скриншотов: `?q=high`, `?q=medium` или `?q=low`.

В кадре работает один финальный проход (`js/finish.js`): сглаживание для устройств без MSAA, мягкая цветокоррекция, лёгкая хроматическая аберрация на десктопе и зерно, которое заодно убирает полосы на тёмных градиентах. Металл, глянец и лампа отражают процедурное «окно с неоном» (`js/env.js`). Дождь и капли на стекле (`js/rain.js`) целиком считаются в шейдере. При `prefers-reduced-motion` дождь, зерно и мигание вывесок замирают.

## Публикация

Сайт публикуется на GitHub Pages workflow-ом `.github/workflows/pages.yml` при каждом пуше в `main`: сначала `npm test`, затем выкладываются `index.html`, `css`, `js` и `vendor`. Один раз нужно включить Pages: Settings → Pages → Source: GitHub Actions. Адрес: https://renfild.github.io/ntoawata/
