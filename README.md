# Renfild — терминал

Одностраничный сайт-портфолио. Страница открывается кадром стола: камера подъезжает к монитору, командная строка живёт на его экране. Стол можно крутить мышью, клавиши печатают команды и сами нажимаются, когда вы печатаете, неоновые вывески открывают проекты. Лампа слева включается щелчком, рыжий кот справа просыпается, если его погладить.

```bash
python3 -m http.server 4173
```

Откройте http://127.0.0.1:4173

Файл по двойному щелчку не заработает: странице нужен локальный сервер из-за модулей JavaScript.

Почта для команды `contact` задаётся в `js/data.js`, поле `profile.email`. Пока оно пустое, терминал показывает только GitHub.

Тексты кейсов собраны из публичных репозиториев, срез GitHub API от 28 сентября 2026.
